## 💰 O Que Você Está Comprando

Um **serviço TypeScript testado em produção** que fala direto com o backend da FreeReels — sem intermediários entre você e a fonte.

- **Sem paywall** — cada episódio é grátis na fonte. Sem conta VIP, sem truques de desbloqueio, nada para manter.
- **Sem necessidade de proxy** — o upstream é amigável a datacenters, um VPS comum funciona. Seu único custo é o servidor.
- **Sem custo por requisição** — nenhuma API de terceiros na cadeia.
- **Pronto para revender / white-label** — seu servidor, suas keys, seus preços.

## ✨ Recursos Principais

- 🎁 **Todos os episódios reproduzíveis** — links de stream HLS diretos, sem conteúdo bloqueado
- 📡 **API de catálogo completa** — abas, feed inicial, feeds de módulos, busca, detalhes
- ⚡ **Cache inteligente** — TTL em camadas, reinícios não atrasam você
- 🔄 **Recuperação automática de sessão** — login anônimo gerenciado e recriado ao expirar
- 🔑 **Sistema de API keys** — tiers, rate limits, cotas diárias
- 🛡️ **O mais barato de operar** — sem pool de proxies, sem emulação de fingerprint TLS, 512 MB de VPS bastam

## ⚡ Início Rápido

```bash
npm install
npm run build && npm start
```

Requisitos: Node.js ≥ 18, qualquer VPS Linux (512 MB de RAM é suficiente). Não precisa instalar banco de dados.
