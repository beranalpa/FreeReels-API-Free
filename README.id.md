## 💰 Apa yang Kamu Beli

**Layanan TypeScript teruji produksi** yang berkomunikasi langsung dengan backend FreeReels — tanpa perantara antara kamu dan sumbernya.

- **Tanpa paywall** — semua episode gratis dari sumbernya. Tidak perlu akun VIP, tanpa trik unlock, tidak ada yang perlu dirawat.
- **Tanpa proxy** — upstream ramah datacenter, VPS biasa langsung jalan. Satu-satunya biaya adalah server.
- **Tanpa biaya per-request** — tidak ada API pihak ketiga di rantainya.
- **Siap dijual kembali / white-label** — server, key, dan harga kamu sendiri.

## ✨ Fitur Utama

- 🎁 **Semua episode bisa diputar** — link stream HLS langsung, tanpa konten terkunci
- 📡 **API katalog lengkap** — tab, home feed, module feed, pencarian, detail
- ⚡ **Caching pintar** — TTL berlapis, restart tidak memperlambat
- 🔄 **Recovery sesi otomatis** — anonymous login ditangani & dibuat ulang saat kedaluwarsa
- 🔑 **Sistem API key** — tier, rate limit, kuota harian
- 🛡️ **Paling murah dioperasikan** — tanpa proxy pool, tanpa emulasi TLS fingerprint, VPS 512 MB cukup

## ⚡ Mulai Cepat

```bash
npm install
npm run build && npm start
```

Kebutuhan: Node.js ≥ 18, VPS Linux apa pun (RAM 512 MB cukup). Tidak perlu install database.
