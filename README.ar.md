## 💰 ماذا تشتري؟

**خدمة TypeScript مُختبَرة في الإنتاج** تتواصل مباشرة مع خوادم FreeReels — بدون وسيط بينك وبين المصدر.

- **بدون قيود مدفوعة** — كل الحلقات مجانية من المصدر. لا حساب VIP، لا حيل فتح، لا شيء للصيانة.
- **بدون حاجة لبروكسي** — المصدر صديق لمراكز البيانات، خادم عادي يعمل مباشرة. تكلفتك الوحيدة هي الخادم.
- **بدون رسوم لكل طلب** — لا واجهة طرف ثالث في السلسلة.
- **جاهز لإعادة البيع / العلامة البيضاء** — خادمك، مفاتيحك، أسعارك.

## ✨ الميزات الرئيسية

- 🎁 **كل الحلقات قابلة للتشغيل** — روابط بث HLS مباشرة، بدون محتوى مقفل
- 📡 **API كتالوج كامل** — تبويبات، خلاصة رئيسية، خلاصات وحدات، بحث، تفاصيل
- ⚡ **كاش ذكي** — TTL متعدد الطبقات، إعادة التشغيل لا تبطئك
- 🔄 **استعادة الجلسة تلقائيًا** — تسجيل الدخول المجهول يُدار ويُعاد إنشاؤه عند الانتهاء
- 🔑 **نظام مفاتيح API** — فئات، حدود معدل، حصص يومية
- 🛡️ **الأرخص في التشغيل** — بدون تجمع بروكسي، بدون محاكاة بصمة TLS، خادم 512 م.ب يكفي

## ⚡ البدء السريع

```bash
npm install
npm run build && npm start
```

المتطلبات: Node.js ≥ 18، أي خادم Linux (ذاكرة 512 م.ب تكفي). لا حاجة لقاعدة بيانات.
